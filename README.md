# Plan Navigator (offline)
No API key, no build, no server code. Files: index.html, sw.js, manifest.webmanifest, netlify.toml.
1. Put the files in a GitHub repo and connect it in Netlify (build command empty, publish dir `.`), or drag the folder into Netlify Drop.
2. Open the HTTPS URL on your phone twice while online (the second load finishes the offline copy). Sensors need HTTPS.
3. Add to home screen: iOS Safari > Share > Add to Home Screen; Android Chrome > menu > Install app.
4. Use: Upload > Start sensors > Calibrate (tap start, walk, tap where you ended) > Pin me > walk.
